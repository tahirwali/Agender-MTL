# Step 0 - data

**Notebook:** `notebooks/step0_data.ipynb` (CPU, internet on, input `agender-mtl-code`, under a minute).

Downloads LAT from PLOS into `data/lat_s1.zip` and writes `step0_summary.json`: the download record with its
SHA-256, the number of rows and columns, the gender counts, the age range, the counts in the six age groups
and the missing cells per column. The data is not changed. Save the output as `agender-mtl-step0`.
